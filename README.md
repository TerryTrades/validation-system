# Data Validation System — Java Swing

## Advanced Programming II

A desktop Java Swing application for capturing personal information and validating each field before it is accepted.

### Fields
- Name and Surname
- Student Number
- Date of Birth
- Age
- Gender
- Contact Number
- Email Address

### Validation
The system demonstrates:
- Presence checks
- Type checks
- Length checks
- Format checks
- Range checks

### How to run
1. Install JDK 8 or later.
2. Open the project in NetBeans, IntelliJ IDEA, or Eclipse.
3. Compile `src/DataValidationSystem.java`.
4. Run the `DataValidationSystem` class.

Command line:
```bash
javac src/DataValidationSystem.java
java -cp src DataValidationSystem
```

## Project notes
The interface uses Java Swing with a planned colour scheme, spacing, labels, status messages and Save/Clear/Exit workflow.
